# 😂 Random Joke Generator

A fun and interactive React application that fetches random jokes from an API and displays them instantly. This project demonstrates API integration, state management, and clean UI development in React.

---

## 🌐 Live Demo

👉 https://api-joke-random.vercel.app/

---

## ⚙️ Tech Stack

- React.js
- JavaScript (ES6+)
- HTML5 & CSS3
- REST API

---

## ✨ Features

- 🎲 Generate random jokes on demand
- ⚡ Fast and lightweight performance
- 🔄 Real-time data fetching using API
- 📱 Fully responsive design
- 🧩 Clean and reusable component structure

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/your-username/api-random-joke.git
```

### 2. Install dependencies

```bash
npm install
```

### 3. Run the project

```bash
npm run dev
```
